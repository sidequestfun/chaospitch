# 🎙️ CHAOS PITCH - Das Partyspiel

Löse absurde Probleme mit noch absurderen Hilfsmitteln. Du bekommst ein Problem und 3 Hilfsmittel. Erfinde eine kreative Lösung – mindestens eines der Hilfsmittel muss vorkommen! Je absurder, desto besser.

Jetzt spielen: [chaospitch.com]([(http://sidequestfun.github.io/chaospitch])

## ✨ Features
* **Spielmodi:** Klassisch, Crime Mode & Speed Mode
* **Custom Decks:** Eigene Karten erstellen und per Link teilen.
* **Leaderboard:** Integriertes Punkte-System für die Spieler.
* **Dark Mode:** Volle Unterstützung für helles und dunkles Design.

## 🔧Tech
- Magic Links enthalten dein komplettes Kartendeck (Base64-kodiert)
- Standalone HTML-Datei mit Tailwind CSS & Alpine.js. Läuft ohne Datenbank.
